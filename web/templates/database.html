Read-only by design. The website connects as a separate database user with SELECT privilege only, and every transaction is READ ONLY. The stored procedures that change data (sp_convert_lead, sp_update_opportunity_stage, sp_record_payment) are run from a SQL client such as MySQL Workbench or the Supabase SQL Editor, not from this site.
