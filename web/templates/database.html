The database behind this site

This site runs on MySQL {{ version }}, using the same database/pulse_crm.sql script that is in the repository and submitted with the project: 18 tables in third normal form, 31 foreign keys, 34 CHECK constraints, 14 unique keys, 6 views, 5 stored procedures and 1 trigger.

Read-only by design. The website connects as a separate MySQL user with SELECT privilege only, and sets every session to READ ONLY. The stored procedures that change data (sp_convert_lead, sp_update_opportunity_stage, sp_record_payment) run in MySQL Workbench, not from this site.
